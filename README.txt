الأمن العراقي الذكي — النسخة التجريبية الأولى

طريقة التشغيل:
1) فك ضغط الملف ZIP.
2) افتح المجلد.
3) انقر مرتين على index.html لفتحه في Chrome أو Edge.
4) جرّب الأقسام ونموذج البلاغ التجريبي.

الملفات:
- index.html : هيكل الموقع
- style.css  : التصميم
- script.js  : التفاعلات التجريبية

ملاحظات مهمة:
- هذه واجهة أولية Front-end وليست نظاماً أمنياً تشغيلياً.
- لا توجد قاعدة بيانات أو خادم أو تسجيل دخول فعلي.
- البلاغات لا تُرسل لأي جهة؛ رقم المتابعة توضيحي فقط.
- لا تدخل أسماء حقيقية أو أرقام هواتف أو عناوين أو معلومات حساسة.
- لا تستخدم النسخة للطوارئ أو لاتخاذ قرارات أمنية.
- قبل أي إطلاق رسمي يلزم تفويض الجهة المالكة، ومراجعة قانونية وأمنية،
  وبنية خادم موثوقة، وتشفير، وتدقيق صلاحيات، وسجلات تدقيق، وسياسة احتفاظ بالبيانات.
